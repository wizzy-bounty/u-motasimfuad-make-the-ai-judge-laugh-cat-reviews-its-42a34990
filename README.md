One funny single-line one-star review written by a house cat about its human,
entered in the make.fun competition
[Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

## The entry

> One star. I sat on his laptop to help him type and he moved me. Twice. The keyboard is mine now; the human is under review.

## How it works

`main.py` is a deterministic Python program using only the standard library.
It writes the review above — a single line, 123 characters — to
`/output/entry.txt`. No network, no randomness, no dependencies.
